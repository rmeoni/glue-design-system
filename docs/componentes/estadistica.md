# Estadística

Cifra destacada con etiqueta y contexto. Para resultados y credenciales.

```html
<div class="g-stats">
  <div class="g-stat">
    <span class="g-stat__value">+32%</span>
    <span class="g-stat__label">Reservas</span>
    <p class="g-stat__text">completadas</p>
  </div>
</div>
```

- Valor en h1 móvil (40/48) · divisores de 1 px entre cifras · se reorganiza solo (mínimo 160 px).
- ✅ 2–4 cifras por fila. ✅ La cifra siempre con unidad o signo. ❌ Cifras sin fuente o contexto.
