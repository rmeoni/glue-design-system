# Footer

Cierre de página con marca, navegación secundaria y legal.

```html
<footer class="g-footer">
  <div class="g-container">
    <div class="g-grid">
      <div class="g-col-md-4 g-col-lg-6">Marca + descripción</div>
      <div class="g-col-2 g-col-md-2 g-col-lg-3">
        <h2 class="g-footer__heading">Navegación</h2>
        <ul><li><a href="#">Trabajos</a></li></ul>
      </div>
    </div>
    <div class="g-footer__bottom"><span>© 2026 UXRodrigo</span><span>Hecho con Glue</span></div>
  </div>
</footer>
```

- Fondo `bg.surface`, texto `text.secondary`, títulos h6, 64 px arriba.
- Los títulos de columna son `<h2>` con estilo h6 para mantener la jerarquía.
